# Group 56 Capstone: True Random Number Generator

This project involves a TRNG that utilizes noise from mouse movements to generate random bits.

## Installation
Currently, the TRNG is incomplete, so it cannot be run. However, onece more components are added, installation will likely look something like the following:
To use the TRNG, clone the GitHub repository and run the file titled final_trng.py.

## Testing
To test the TRNG, following installation of the repo, use entropy.py to check the entropy levels of the values it outputs.
